## B. 새 프로브를 직접 만들기 (10초, GPU 불필요)

`open` 폴더에서 (Git Bash 또는 PowerShell):

```bash
python scripts/make_probe.py --wl 0.20 --temp 0.32
python scripts/make_probe.py --wl 0.30 --temp 0.40
```

→ `probe_wlXX_tYY.zip` 이 생김. 그대로 DACON 제출.
- `--wl` : LGBM 가중치 (0.15~0.35 사이 탐색). mmBERT 비중 = 1 - wl.
- `--temp` : mmBERT 온도 (0.3~0.6). 낮을수록 확률이 뾰족해짐.
- scale은 항상 자동으로 꺼짐(no-scale) — 이건 이미 확정된 최적.

**전략**: 한 번에 한 값만 바꿔서 LB 반응을 본다. 오른 방향으로 더 밀고, 내리면 멈춘다.
검증 점수는 무시(0.002 이하 차이는 노이즈, LB만 믿는다).

## C. GPU로 새 모델 학습 (반나절, 점수 상방이 더 큼)

미세 프로빙이 막히면(0.791 근처에서 정체) 새 모델이 필요하다. 셋 다 세션 종료와 무관하게
백그라운드로 도는 방식(PowerShell `Start-Process`).

### C-1. ID토큰 시드 2호기 (가장 안전, +0.002~0.004 기대)
지금 모델과 시드만 다른 100% 모델을 만들어 더 좋은 쪽을 채택.
```powershell
$env:PYTHONIOENCODING="utf-8"
Start-Process python -ArgumentList "scripts/train_strategy_c2.py --model ./strategy_c_work/mmbert_src --epochs 3 --batch 16 --max-len 512 --lr 3e-5 --seed 2026 --ser v2 --full --out ./strategy_c_work/idtok100_s2026" -WindowStyle Hidden -RedirectStandardOutput "strategy_c_work/s2026.log" -RedirectStandardError "strategy_c_work/s2026.err"
```
진행 확인: `Get-Content strategy_c_work/s2026.log -Tail 3` (약 8~10시간).
완료 후 조립: **아래 D 참고.**

### C-2. 신호 토큰 추가 실험 (+0.003~0.008 기대, 상방 큼)
ID토큰이 통했으니 다른 강신호도 텍스트에 주입. `scripts/serialize_full.py`의
`build_text_full_v2`를 참고해 `_v3` 함수를 만들고(예: last CI 상태·open_files 개수·
직전 result의 PASS/FAIL를 토큰으로), train_strategy_c2.py에 `--ser v3` 추가.
→ Claude에게 "serialize_full에 v3 만들어줘"라고 하면 빠름. 혼자면 v2를 복사해 수정.

## E. 꼭 지킬 것 (실패 방지)

- **requirements.txt 건드리지 말 것** — `transformers==5.9.0` 고정이 mmBERT 작동의 핵심.
  버전 지우면 서버 구버전이 로드돼 조용히 LGBM 폴백(→ 0.741로 추락).
- **scale은 항상 끄기** (make_probe가 자동 처리). 켜면 검증 과적합으로 LB 하락.
- **zip 용량 1GB 이하** (현재 254MB, 여유 충분). **추론 10분 제한** — 모델 1개만 넣기(2개는 초과).
- 새 모델 제출 전 **반드시 30k 리허설** — 안 하면 시간초과/폴백으로 슬롯 날림.
- 제출은 **한 번에 한 요소만** 바꿔서 원인을 분리.
